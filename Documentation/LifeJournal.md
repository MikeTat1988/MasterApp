# LifeJournal

LifeJournal is a personal-use photo diary built into MasterApp. It opens at `/life`, shows the current local day by default, and presents photos as printed cards pinned onto a cork board.

## How to Open

- Local: `http://localhost:19057/life`
- Through the configured Cloudflare Tunnel: open the MasterApp public URL and append `/life`.

## What It Does

- Opens today by default using the local server date.
- Lets you take/select a photo from iPhone Safari with `<input type="file" accept="image/*" capture="environment">`.
- Compresses the photo in the browser when possible, then uploads it to MasterApp.
- Stores the server-side compressed JPEG and metadata in local files.
- Records `Woke Up` and `Went To Sleep` events.
- Runs day analysis manually with `Analyze Now` or automatically after the local finalization hour.
- Shows prior days at `/life/history`.

## Storage Paths

Runtime data is stored under:

`%LOCALAPPDATA%\MasterApp\State\LifeJournal\`

Structure:

```text
photos\
  yyyy-MM-dd\
    HH-mm-ss-guid.jpg
days\
  yyyy-MM-dd.json
analysis\
  yyyy-MM-dd.md
  yyyy-MM-dd.raw.txt
  yyyy-MM-dd.analysis.json
assets\
  cork_board_bg.png
  photo_card_frame.png
  pin_red.png
  pin_blue.png
  staple.png
  paper_note_bg.png
logs\
  lifejournal.log
finalizer-state.json
```

Repo assets are stored in:

`src\MasterApp\wwwroot\life\assets\`

They are generated by:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\generate-lifejournal-assets.ps1
```

## API Endpoints

- `GET /api/life/today`
- `GET /api/life/day?date=yyyy-MM-dd`
- `POST /api/life/photo`
- `POST /api/life/event`
- `POST /api/life/analyze`
- `GET /api/life/history`
- `GET /api/life/photo/{date}/{filename}`

`POST /api/life/photo` accepts multipart form data with a `photo` file. The server generates all filenames and rejects non-image uploads.

`POST /api/life/event` body:

```json
{
  "type": "woke_up"
}
```

Allowed values are `woke_up` and `went_to_sleep`.

`POST /api/life/analyze` body is optional:

```json
{
  "date": "2026-05-07"
}
```

## Codex CLI Dependency

LifeJournal uses the local Codex CLI for private photo-day analysis. The default executable is `codex`, but the analyzer resolves through MasterApp's configured Codex command when LifeJournal is still at the default.

The analyzer starts Codex with `ProcessStartInfo.ArgumentList`, not shell string concatenation. The image command shape is:

```text
codex exec --skip-git-repo-check --sandbox read-only --image "img1.jpg" -- "<prompt>"
```

MasterApp resolves `codex` away from protected WindowsApps/MSIX aliases and prefers the real Codex CLI under `%LOCALAPPDATA%\Packages\OpenAI.Codex_*\LocalCache\Local\OpenAI\Codex\bin\codex.exe`, with `%USERPROFILE%\.codex\.sandbox-bin\codex.exe` as a fallback.

If Codex is missing, fails, times out, or returns invalid output, LifeJournal saves a conservative fallback summary and logs the failure.

## Auto-Finalization

LifeJournal runs a small background finalizer inside MasterApp.

- It checks on startup and then periodically.
- After local `03:00`, it looks at yesterday.
- If yesterday has photos and no analysis, it runs analysis and marks the day finalized.
- It stores duplicate-run state in `finalizer-state.json`.
- Loading `/life` also requests a safe background check without blocking the UI.

## iPhone / Cloudflare Tunnel Test

1. Start MasterApp.
2. Make sure the Cloudflare Tunnel is connected from the MasterApp tray/dashboard.
3. On iPhone Safari, open the public MasterApp URL.
4. Navigate to `/life`.
5. Tap `Take Photo`, capture/select an image, and confirm it appears as a pinned card.
6. Tap the card to preview it.
7. Tap `Analyze Now` and confirm a story note is saved.
8. Open `/life/history` and confirm the day appears as a paper note.
